# avito-autoposter

Локальный полуавтоматический помощник для продавца на Авито (Windows): сам открывает формы «Разместить объявление», заполняет их по шаблону и **оставляет вкладки открытыми**, чтобы человек проверил, выбрал адрес и нажал «Опубликовать». Плюс наблюдатель, который присылает в Telegram уведомление о новых сообщениях, и карта метро для учёта, где объявления набирают больше просмотров.

*English, in short:* a Windows-only Playwright/CDP helper that pre-fills Avito listing forms (iPhone category by default) in a real Chrome window, never publishes by itself, plus a Telegram notifier for new messages and a metro heat-map of views. Configuration, texts and photos are yours; nothing personal ships in this repo. Documentation is in Russian; `AGENTS.md` is written so an AI coding agent can install and operate the project.

> **Важно.** Проект не обходит капчу и проверки Авито: их проходит человек сам. Автоматизация действий на Авито может противоречить правилам площадки, аккаунт может быть ограничен или заблокирован. Никаких гарантий нет, вы используете проект на свой риск и отвечаете за достоверность текстов объявлений.

## Что умеет

| Часть | Что делает |
|---|---|
| **Сайт автовыкладки** (`автовыкладка/`, http://127.0.0.1:7777) | Вы выбираете, сколько каких объявлений нужно, правите цены. Кнопка «Заполнить формы» открывает по вкладке на объявление и заполняет заголовок, характеристики, фото, описание, цену. Адрес, выключение Авито Доставки, ставку и кнопки «Продолжить» и «Опубликовать» делаете вы руками. Около минуты на форму. |
| **Тексты** (`textgen.py`, `шаблон_описания.txt`) | Один шаблон описания, из него для каждого объявления делается своя версия: у каждой строки своя подмена похожих по виду символов (а→a, е→e, о→o/0, з→3) и свой вариант заголовка. Подмена ухудшает читаемость и поиск; её можно отключить, оставив в шаблоне только свой текст и убрав вызов `sub()` в `textgen.py`. |
| **Фото** (`photos.py`) | Для каждой формы заново делает уникальные копии ваших фото (поворот, кадрирование, цвет, шум, без EXIF) во временную папку, загружает по одной, затем удаляет. Фото №1 всегда первое, остальные в случайном порядке. |
| **Единый Chrome** (`browser_host.py`) | Один настоящий Chrome с вашим профилем Авито, окно скрыто. Сайт показывает его кнопкой и снова прячет, ничего не перезапуская и не перелогиниваясь. |
| **Обход VPN** (`direct_proxy.py`) | Если у вас системный VPN, а Авито он мешает (проверки по IP): локальный прокси выпускает трафик *только этого Chrome* мимо VPN. Остальной компьютер остаётся за VPN. Можно отключить. |
| **Наблюдатель** (`avito_watch.py`) | Раз в минуту читает счётчик непрочитанных чатов с уже открытой вкладки (без перезагрузки страницы) и шлёт в Telegram. Сам поднимает Chrome и чинит его, если он завис. |
| **Сторож** (`avito_guard.py`) | Каждые 5 минут проверяет, что наблюдатель жив, и пишет в Telegram, если нет. |
| **Карта метро** (`карта_метро/`) | Из таблицы `статистика_выкладок.csv` собирает страницу `карта.html`: схема метро Москвы и Петербурга, цвет станции = просмотры в день на объявление, фильтры по модели. |

## Требования

- Windows 10/11, права администратора не нужны (только для необязательных маршрутов мимо VPN).
- Google Chrome.
- Python 3.10 или новее (python.org, отметить «Add to PATH»).
- Аккаунт Авито (входите сами, пароль и SMS никуда не передаются).
- По желанию: Telegram-бот для уведомлений.

## Установка

```powershell
git clone https://github.com/Hodaska/avito-autoposter.git
cd avito-autoposter
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт создаёт `.venv`, ставит зависимости, создаёт `settings.json` и `автовыкладка\config.json` из примеров и настраивает автозапуск (наблюдатель, сторож, сайт). Что он сделает, можно посмотреть заранее: `install.ps1 -DryRun`. Удалить автозапуск: `uninstall.ps1`.

Telegram сразу при установке: `install.ps1 -TelegramToken "123:ABC" -TelegramChatId "123456789"`.

## Первый запуск

1. Запустите сайт: `автовыкладка\запуск_сайта.bat` (или перезагрузитесь, он стартует сам). Откроется http://127.0.0.1:7777.
2. Сайт поднимет скрытый Chrome с профилем `profile_account` и сам покажет его окно. **Войдите в Авито вручную** (логин, SMS). Сессия сохранится в профиле. Если Авито покажет капчу или проверку, пройдите её сами.
3. Запустите наблюдателя (после установки он стартует при входе в Windows; сразу: `.venv\Scripts\pythonw.exe avito_watch.py`).
4. Положите оригиналы фото в папки `фото\<название>\` с числовыми именами `1.png`, `2.jpg`, … (до 10 штук). Названия папок заданы в `config.json` (`photo_dir`).
5. Откройте сайт, проверьте цены и количество, нажмите «Показать тексты» (посмотреть заголовки и описания), затем «Заполнить формы». Первый раз начните с одной формы и наблюдайте.
6. В каждой открытой вкладке: адрес, Авито Доставка (выключить), ставка за просмотр, «Продолжить», «Опубликовать».
7. Закончив, нажмите на сайте «Я закончил работу: спрятать браузер».

## Настройка

- **`автовыкладка/config.json`** (создаётся из `config.example.json`, правится и на сайте): `models` (для каждого типа объявления: `name`, `mem`, `color`, `color_avito`, `price`, `photo_dir`, `count`, `others`, `need`), общие `sim`, `sim_text`, `address`, `ad_kind`, `country`, `offer_off`, `history`, `kit`, `package`, `desc_mode` (`paste` быстро, `type` посимвольно, около 2 минут на объявление).
- **`автовыкладка/шаблон_описания.txt`**: текст с подстановками `{NAME}`, `{MEM}`, `{COLOR}`, `{OTHERS}`, `{SIM}`, `{ADDR}`, `{NEED}`. **Замените примеры на правду о вашем магазине и товаре.**
- **`settings.json`** (из `settings.example.json`, необязательно): `bypass_vpn` (true/false), `gateway` (IP роутера, иначе определяется сам), `chrome_path`.
- **Telegram**: создайте бота через @BotFather (`/newbot`), получите токен; напишите боту любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, в ответе `chat.id` это ваш `chat_id`. Положите в `secrets\telegram.json` (образец `secrets\telegram.example.json`) или в переменные окружения `TG_TOKEN`, `TG_CHAT_ID`. Файл в репозиторий не попадает (`.gitignore`). Если в вашей сети Telegram недоступен без VPN, проверьте, что `api.telegram.org` открывается из того процесса, в котором работает наблюдатель.

## Обход VPN (только если нужен)

Если Авито при включённом VPN просит «проверку IP», а отключать VPN целиком не хочется:

- **Способ 1 (по умолчанию, без администратора):** `settings.json` → `"bypass_vpn": true`. Chrome с профилем Авито запускается с `--proxy-server` на локальный `direct_proxy.py` (порт 8899), который привязывает исходящие сокеты к адресу физической сетевой карты, поэтому трафик идёт мимо туннеля. Работает с VPN, которые сохраняют обычный маршрут в локальной сети (проверено на sing-box TUN). IP роутера определяется сам, при ошибке укажите `gateway`.
- **Способ 2 (от администратора):** `avito_direct_on.ps1` добавляет постоянные маршруты для подсетей Авито через роутер; убрать: `avito_direct_off.ps1`. Подсети Авито меняются, список в скрипте может устареть.
- VPN нет или Авито и так открывается: поставьте `"bypass_vpn": false`.

## Карта метро

```powershell
.venv\Scripts\python.exe карта_метро\build.py
```

Берёт `статистика_выкладок.csv` (если нет, то `статистика_выкладок.пример.csv`), создаёт `карта_метро\карта.html`, открывается двойным щелчком. Формат таблицы: `Выкладка №; Дата записи; Город; Место (метро/район); Просмотров; Срок, дней; Просмотров в день; Что дальше; Заметка; Модель`. Строка с пометкой «не перевыложено» в заметке дополняет предыдущее объявление на том же месте (история просмотров). Координаты станций получены из публичного справочника метро hh.ru (`метро.json`, без МЦД).

## Что не проверено

Работа на другом компьютере и после чистой установки по этой инструкции; пакеты в десятки форм подряд; реакция Авито на скорость и объём. Селекторы формы привязаны к текущей вёрстке Авито и сломаются, когда она изменится (см. `docs/AVITO_FORM.md`, `recon.py`).
