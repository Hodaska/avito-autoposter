# Форма Авито: путь и селекторы

Снято на живой форме категории «Электроника → Мобильные телефоны» (ноябрь 2026). Вёрстка Авито меняется, при поломке запустите `автовыкладка\recon.py` при открытой форме (только чтение, пишет в `автовыкладка\debug\recon`: URL, скриншот, поля вкладок; файлы содержат личные данные аккаунта, никуда не выкладывать) и обновите маркеры в `filler.py`.

## Путь

1. Главная `avito.ru`, ссылка `a[href="/additem"]` («Разместить объявление»), открывается Ctrl+кликом в **новой вкладке**.
2. Мастер категорий: «Электроника».
3. Поле `#title`: ввод заголовка. Кнопка-подсказка `category-title` «Мобильные телефоны».
4. Вся форма на одной странице. Авито сам определяет Apple и модель по заголовку.

## `data-marker` полей

| Поле | Маркер |
|---|---|
| Состояние | `params[110395]/option` |
| Вид объявления | `params[2822]/option` («Товар приобретён на продажу») |
| Память | `memory_size`, варианты `memory_size/custom-option(...)` |
| Цвет (появляется после памяти) | `color`, варианты `color/custom-option` (у 17 Pro Max: Оранжевый, Серебристый, Синий) |
| SIM | `params[184666]/option` |
| Страна | `params[199748]/input`, `/clear`, `/option` |
| История | `params[184667]/option` |
| Комплект | `params[148127][]/option` (чекбоксы; «Коробка» бывает уже отмечена) |
| Упаковка | `params[167055]/option` |
| Фото | `add/input` (input[type=file], multiple; грузим по одной в нужном порядке) |
| Описание | `description-html-editor [role=textbox]` (Draft.js; `insert_text` работает, списки не автоформатируются) |
| Цена | `#price` |
| «Предложение со скидкой» | `input[name="params[195944]"]` (выключается) |
| Адрес | `geo/search-input` (скрипт не трогает) |
| Далее | `item-edit/button-next` «Продолжить» (скрипт НЕ нажимает) |

Блока «Авито Доставка» до ввода адреса на форме нет, её выключает человек вместе с адресом. «Мультиобъявление» не трогаем.

## Счётчик сообщений (наблюдатель)

Вкладка `https://www.avito.ru/profile/messenger`, элемент `[data-marker="header/unread-chats-counter"]` (число непрочитанных чатов), список чатов `channels/channelLink`, последнее сообщение `channels/last-message`. Признак логина: `[data-marker="header/login-button"]`. Заголовок страницы «Доступ ограничен» = блок/проверка по IP.

## Если маркер перестал находиться

`filler.py` останавливается с «не нашла на странице: …» и оставляет вкладку. Откройте форму руками, запустите `recon.py`, найдите новый маркер (или текст кнопки), поправьте в `filler.py` (`m("маркер")`, `exact("текст")`), проверьте одну форму.
